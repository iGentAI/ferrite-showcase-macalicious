## The desktop

Start here. The Desktop demo is a whole Catalina screen in the page: a menu bar, a Dock, the
desktop's icons and a window manager that runs every application demo below as a window you
can move, resize, minimize, zoom and close.

The same desktop also runs as a [full-window page](/desktop/), without the documentation around
it. Open that one to use the desktop as a desktop. Launchpad, Siri and Spotlight are system
overlays, not applications: the desktop has no window for them. It opens them over the
windows, Launchpad from its Dock tile and Spotlight and Siri from their menu bar extras, and
each has its own page ([Launchpad](/demos/launchpad), [Siri](/demos/siri),
[Spotlight](/demos/spotlight)).

## Applications

Each demo rebuilds one Catalina application from the library's components, adding its own
layout, data and stand-in artwork. It is compared with its
reference screenshot like a component. A demo imports the library through its public paths,
as your code does, so
its source in `demos/<app>/` is a worked example of composition; [Building an app](/building-an-app)
explains how the pieces go together. The cards are generated from the demo folders, and the
pictures are taken from this site by its own build.

<PageList group="Demos" except="desktop" gallery="large" empty="No demo pages have been built into this site." />

No Apple artwork is included: application icons, photographs and desktop pictures in the demos
are original stand-ins ([Fidelity limits](/fidelity#artwork)).
