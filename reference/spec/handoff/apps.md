## Deviations, concerns, discoveries and assumptions

- **Deviations:** the scratch audit is under `reference/spec/.scratch/appsfin/` because the file tool refused writing the native absolute scratch path; it is not a library deliverable. Large handoff edits were accepted without truncation, but exceeded the brief's approximate 12,000-character-per-call precaution. The handoff itself was nevertheless written in exactly three successful calls (create + two appends).
- **Concerns:** the requested verifier's parser leaves most inherited shorthand measurements unchecked. Passing it is narrower than verifying every table value. The 48-sample audit and manual matrix/plot checks are reported separately rather than inflating its count.
- **Discoveries affecting other work:** use app-specific dark-persistent palettes for Calculator/FaceTime/QuickTime; do not equate dark-style UI with identical screenshot bytes. TV has no LCD. Home on tiles and store pill fills stay light in dark mode. Voice Memos has no demonstrated played/unplayed colour split.
- **Assumptions instead of questions:** component-specific multi-sample specs take precedence over older blueprint summaries; nominal overview-handle width includes fractional antialiasing, not only full-colour pixels; unknown native interactions remain [I]. No owner input was required to complete the authorized files/audit.
