## Not reproducible in a browser
- Behind-window vibrancy/wallpaper tinting: page backdrop-filter sees only page content, not other apps/desktop. Use measured opaque fallbacks or the inferred page-local blur/tint recipes.
- Window-server raster shadows and native SF glyph AA: use fitted Gaussian layers and licensed SF fonts at DPR2; fractional strokes need DPR1 adjustment. Fits and raster-baseline proxies are not native assets/font-engine baselines.
- Spaces/window-server tiling/traffic-light behaviour: emulate in-page drag/resize/layout. Fullscreen API hides browser chrome but cannot assign macOS Spaces or command the system menu bar.
- PiP over other apps: native browser PiP API where available; fixed DOM video floats only within the page.
- AX/key loops/reserved shortcuts: map to ARIA/roving focus and equivalent handlers; some browser/OS shortcuts cannot be intercepted.
- Quick Look/Markup/Share extensions: real local preview content and redrawn SVG tools; a custom menu cannot invoke arbitrary AppKit services. Web Share provides a different native picker.
- Historical web content and artwork/icons: live sites can change/refuse framing. Use local static content/assets for the capture; do not claim an iframe reproduces 2019 pages.
