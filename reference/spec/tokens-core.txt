# Curated core tokens: source for `tools/build.py tokens`.
#
# One token per line:  css-name | light | dark | tag | evidence | note
# - Colours are STORED pixel values (see CONVENTIONS.md); the build step adds the sRGB value for CSS.
# - `=` in the dark column means "same as light".
# - Names follow the scaffold's token layer (src/styles/tokens/*.css). The build step marks each name
#   as existing there or as a proposed new name.
# - Evidence names the component spec that holds the pixel citations, plus one direct citation where
#   the lead re-sampled the value. Filenames omit the common prefix `10-15-Catalina-` and `.png`.
