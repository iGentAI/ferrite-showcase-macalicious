---
title: Section Header
description: The header of a group in a grouped collection or list, a bold title with an optional action at the trailing edge, plain in the content or pinned as a band while its group scrolls.
---

<Example name="basic" both />

A collection view that is grouped (Finder with Use Groups, a search that sorts its results by
kind) puts a header above each group: the group's title in bold and, where a group is cut
short, an action such as "Show All (553)" at the other end. AppKit draws it as the section
header of an `NSCollectionView`. Base UI has no such primitive; the bar is a `<div>`, the title
a heading element, and the action is built on
[Base UI's Button](https://base-ui.com/react/components/button).

## Usage

```tsx
import { SectionHeader, SectionHeaderAction } from "macalicious/section-header";
import "macalicious/section-header.css";

<SectionHeader
  titleId="documents"
  accessory={<SectionHeaderAction onClick={showAll}>Show All (553)</SectionHeaderAction>}
>
  Documents
</SectionHeader>
<ul aria-labelledby="documents">…</ul>
```

Or copy the source into your project: `npx macalicious add section-header`.

The header is as wide as its container, and its box includes its padding: 32 pt high with the
rule of a plain header, 31 pt as a pinned band, whose separator is drawn under the box. Put it
directly above the group it names, on the content's own background. To hold a header at the
top of the scrolling view while its group passes under it, give it `variant="pinned"` and
`position: sticky; top: 0`.

This is not the header of a table's columns ([Table Header](/components/table-header)) and not
the small grey heading of a [sidebar](/components/sidebar) section.

## Guidelines

- Name a group with a short noun in title-style capitalisation: "Folders", "PDF Documents".
- Show an action only when it changes what the group shows. Say how many items it reveals:
  "Show All (553)", then "Show Less".
- Use headers only when the content is grouped by an attribute the person chose or would
  expect. Do not use them to decorate a short list.

These paraphrase Apple's Human Interface Guidelines for macOS and Finder's own behaviour; they
are not verified against the archived guideline text.

## Variants and states

<Example name="variants" both />

| `variant` | Drawn as | Use |
| --- | --- | --- |
| `plain` (default) | A hairline rule above the title, on the content's background | A header inside the scrolling content |
| `pinned` | A grey band with a separator under it | The header held at the top of the view |

`SectionHeaderAction` is secondary text without a bezel. Pressed, it takes the label colour;
disabled, the tertiary label colour; with keyboard focus in the key window it has the focus
ring. The bar itself has no states and looks the same in a window that is not key.

## Sizes

One size: a 31 pt bar, a 14 pt bold title 12 pt from the leading edge and an 11 pt action 15 pt
from the trailing edge. Catalina shows no smaller or larger section header.

## API

<PropsTable name="SectionHeaderProps" />

`SectionHeader` also accepts every prop of a `<div>`.

<PropsTable name="SectionHeaderActionProps" />

`SectionHeaderAction` accepts every prop of Base UI's Button: `disabled`,
`focusableWhenDisabled`, `render` and the attributes of a `<button>`.

| Attribute | On | Values | Description |
| --- | --- | --- | --- |
| `data-variant` | `SectionHeader` | `plain`, `pinned` | How the bar is drawn. |
| `data-disabled` | `SectionHeaderAction` | present | The action is disabled. |

Parts: `.mac-section-header`, `.mac-section-header-title`, `.mac-section-header-accessory`,
`.mac-section-header-action`.

## Accessibility

- The title is a heading element, `<h2>` by default. Choose `level` so that it fits the
  outline of the page: one below the heading of the view the groups are in.
- Give the title an id with `titleId` and point the group at it with `aria-labelledby`, so
  that a list or grid is announced with its group's name. An `id` on the header itself would
  name the group by everything in the bar, the action included.
- The accessory is outside the heading: a screen reader reads "Documents", not "Documents Show
  All (553)".
- `SectionHeaderAction` is a button: focusable, pressed with Return or Space. For an action
  that expands a group, set `aria-expanded`.
- In forced-colours mode the rule and the band's separator are drawn in the system text colour.
