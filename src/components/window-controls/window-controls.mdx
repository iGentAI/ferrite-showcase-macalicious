<Example name="basic" both />

The three round buttons people call the traffic lights. Each is Base UI's
[Button](https://base-ui.com/react/components/button). They only report activation: closing,
minimizing and zooming belong to the application or its window manager.

## Usage

```tsx
import { WindowControls } from "macalicious/window-controls";
import "macalicious/window-controls.css";

<WindowControls onClose={close} onMinimize={minimize} onZoom={toggleFullScreen} />
```

Pass the element to a [Title Bar](/components/title-bar) as its `controls`, which places it:
centres 14, 34 and 54 pt from the window's edge in a titled bar, 19, 39 and 59 pt in the 38 pt
bar.

For a different set of buttons, pass `WindowControlsButton` children:

```tsx
import { WindowControls, WindowControlsButton } from "macalicious/window-controls";

<WindowControls>
  <WindowControlsButton kind="close" aria-label="Close" onClick={close} />
</WindowControls>
```

## Guidelines

Not verified: this section paraphrases Apple's Human Interface Guidelines and was not checked
against Apple's text.

- Keep all three in their usual order. Disable the ones that do not apply (`zoomDisabled` for a
  window that cannot be resized, `minimizeDisabled` in full screen) instead of removing them.
- The zoom button enters full screen in a window that supports it; set `zoomRole="zoom"` for
  one that only zooms, and `"exit-full-screen"` while the window is full screen.
- Set `edited` on a document window with unsaved changes: a dot appears in the close button.

## Variants and states

<Example name="states" both hideCode />

| State | How it is triggered | Look |
| --- | --- | --- |
| Key window | no attribute, or `key` on the window | Red, yellow and green; in Aqua a darker half-point ring |
| Pointer over the group, or keyboard focus inside | `:hover`, `:has(:focus-visible)` | Glyphs on all three |
| Pressed | `:active` | The fill darkens (provisional) |
| Disabled | `closeDisabled`, `minimizeDisabled`, `zoomDisabled` | Grey disc, no glyph |
| Edited | `edited` | A dot in the close button while the pointer is away |
| Main window | `data-window-state="main"` on an ancestor | All three grey |
| Inactive window | `data-window-state="inactive"` on an ancestor | All three a lighter grey |
| Graphite | `data-accent="graphite"` on the group or an ancestor | All three graphite |

In a window that is not key the buttons take their colours back while the pointer is over the
group, and turn grey again when it leaves. This is native Catalina behaviour recorded as an
inference: no reference screenshot shows the pointer over the controls of a main or inactive
window. A disabled button stays grey, and keyboard focus inside the group shows the glyphs
without restoring the colours. The window state is not a prop: the group reads
`data-window-state` from the window it is in.

## API

| Attribute | On | Values | Description |
| --- | --- | --- | --- |
| `data-size` | group | `regular`, `small` | Reflects `size`. |
| `data-kind` | button | `close`, `minimize`, `zoom` | Which button it is. |
| `data-edited` | close button | present or absent | Reflects `edited`. |
| `data-disabled` | button | present or absent | Set by Base UI while the button is disabled. |
| `data-force` | group or button | `hover`, `pressed`, `focus` | Documentation and visual tests only. |

## Accessibility

- The group has `role="group"` and the name "Window controls"; pass `aria-label` to translate
  it. Each button is a native `<button>` named "Close", "Minimize" and, by `zoomRole`, "Enter
  Full Screen", "Zoom" or "Exit Full Screen"; `closeLabel`, `minimizeLabel` and `zoomLabel`
  replace them.
- The buttons are in the tab order, which is macOS with full keyboard access on (by default
  macOS leaves them out of the key loop). Space and Return activate. To take them out, pass
  `WindowControlsButton` children with `tabIndex={-1}` and offer the commands in a menu.
- The glyphs also show while a button has keyboard focus, so the three are not told apart by
  colour alone at that moment. At rest they are told apart by position and by name.
- A disabled button leaves the tab order.
