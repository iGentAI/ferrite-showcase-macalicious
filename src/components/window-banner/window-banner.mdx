<Example name="basic" both />

Finder draws this strip above a folder's contents to state a property of the folder ("Shared
Folder"). It is a note, not a control: 25 pt high, bold small text at the leading edge, with the
same fill and separator rows as the Finder [Scope Bar](/components/scope-bar).

## Usage

```tsx
import { WindowBanner } from "macalicious/window-banner";
import "macalicious/window-banner.css";

<WindowBanner>Shared Folder</WindowBanner>
```

Place it under the [Title Bar](/components/title-bar) or the
[Window Tab Bar](/components/window-tab-bar) and above the content it describes. In Finder it
spans the content area only, not the sidebar.

With an action at the trailing edge:

```tsx
import { WindowBanner, WindowBannerAction } from "macalicious/window-banner";

<WindowBanner trailing={<WindowBannerAction onClick={connect}>Connect As…</WindowBannerAction>}>
  Shared Folder
</WindowBanner>
```

## Guidelines

Not verified: this section paraphrases Apple's Human Interface Guidelines and was not checked
against Apple's text.

- Use a banner for a standing fact about what the window shows, not for transient messages or
  errors; those are alerts or notifications.
- Keep the text to a few words. It is cut at the end when it does not fit.
- At most one action, and only one that concerns the fact stated.

## Variants and states

| State | How it is triggered | Look |
| --- | --- | --- |
| Text only | – | Measured (Finder Home, Finder Gallery View) |
| With an action | `trailing` | Round-rect button as on the scope bar (provisional: no screenshot shows it) |
| Action pressed, focused, disabled | `:active`, `:focus-visible`, `disabled` | provisional; the focus ring shows in the key window only |

## Sizes

One size: the banner is 25 pt high and as wide as the window; its buttons are 16 pt high.

## API

<PropsTable name="WindowBannerProps" />

<PropsTable name="WindowBannerActionProps" />

Parts: `.mac-window-banner-text` and `.mac-window-banner-trailing`. `data-force` (`pressed`,
`focus`) on an action pins a transient state in documentation and visual tests.

## Accessibility

- `role="note"`. Pass `role="status"` if the banner appears or changes while the window is open
  and should be announced.
- `WindowBannerAction` is a native button: Space and Return activate it, Tab reaches it, and a
  disabled one leaves the tab order.
