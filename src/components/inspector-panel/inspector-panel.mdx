title: Inspector Panel

<Example name="basic" both />

Finder's Get Info window: a standard title bar with a proxy icon, a header that names the item,
and sections stacked under 1 pt separators, each with a disclosure triangle and a bold title.
The same layout serves an inspector, which follows the selection instead of staying with one
item. Sections are built on
[Base UI's Collapsible](https://base-ui.com/react/components/collapsible); the frame is the
library's [Window](/components/window) and [Title Bar](/components/title-bar).

## Usage

```tsx
import {
  InspectorPanel,
  InspectorPanelHeader,
  InspectorPanelItem,
  InspectorPanelList,
  InspectorPanelSection,
} from "macalicious/inspector-panel";
import "macalicious/styles.css";

<InspectorPanel title="Report.pdf Info" icon={<DocumentIcon />} onClose={close}>
  <InspectorPanelHeader
    icon={<DocumentIcon />}
    title="Report.pdf"
    detail="2.4 MB"
    subtitle="Modified: Today at 9:41 AM"
  />
  <InspectorPanelSection title="General:" defaultOpen>
    <InspectorPanelList>
      <InspectorPanelItem label="Kind:">PDF document</InspectorPanelItem>
      <InspectorPanelItem label="Size:">2,412,544 bytes</InspectorPanelItem>
    </InspectorPanelList>
  </InspectorPanelSection>
  <InspectorPanelSection title="Comments:">…</InspectorPanelSection>
</InspectorPanel>
```

- A section is collapsed unless `defaultOpen` or `open` says otherwise. Control it with `open`
  and `onOpenChange` to remember which sections were open.
- A section's content is free: an `InspectorPanelList` of labelled values, or small controls
  (`size="small"`) with the section's 12.5 pt side margins.
- The panel is as tall as its sections, so it grows and shrinks as they open and close, as in
  Finder. With a `height` the body scrolls instead.
- The window does not move, order or close itself: a window manager gives it `state` and a
  position through `style`, moves it from `onDragRegionPointerDown` (a press on the title bar,
  not on a window control), and unmounts it on `onClose`.

## Guidelines

From the Human Interface Guidelines for macOS,
[Panels](https://web.archive.org/web/20200503145009/https://developer.apple.com/design/human-interface-guidelines/macos/windows-and-views/panels/):

- An inspector shows, and sometimes edits, the attributes of the current selection. Keep it
  up to date: when the selection or its attributes change, the inspector changes with them.
- An Info window shows the attributes captured when it was opened and keeps showing them when
  the selection changes. It is a standard window: it does not float above other windows, it
  can be minimized, and it is listed in the Window menu.
- Title a panel after its purpose, with a noun or a noun phrase in title-style capitalisation.

Not from that page: Finder's Info window uses small text and small controls throughout
(measured), and the keyboard behaviour of the section headers (Right Arrow expands, Left Arrow
collapses) follows the measured spec's reading of the Disclosure Controls page, which was not
checked here.

| --- | --- | --- |
| Section expanded | Triangle points down; content shown | Measured (General, Open with) |
| Section collapsed | Triangle points right; header only, 19 pt | Measured (Comments, Preview) |
| Section disabled | Title dimmed, cannot be toggled | Provisional: no screenshot |
| Keyboard focus on a header | Focus ring inside the header | Provisional: no screenshot |
| Inactive window | Standard inactive title bar; content unchanged | Provisional: no screenshot |

## Sizes

One size: small text (11 pt) throughout, a 13 pt bold name in the header. The window is 265
points wide by default, Finder's width, and is not resizable in width. A list's label column
fits its longest label; set `--mac-inspector-panel-label-width` on a list, a section or the
panel to line lists up, as Finder does per section.

## Accessibility

- The panel is a `region` named by its title.
- A section's header is one `button` with `aria-expanded`, pointing at its content with
  `aria-controls`. Space and Return toggle it; Right Arrow expands and Left Arrow collapses.
  Every header is in the tab order.
- Collapsed content is not in the DOM (unless `keepMounted`), so it is not read or focused.
- A list is a description list (`dl`, `dt`, `dd`): each value is announced with its label.
- The header's icon and the proxy icon are decorative and hidden from assistive technology.
- In forced-colours mode the separators and triangles use system colours.

Apple artwork and the tags field is a token field; the example leaves them out and the
