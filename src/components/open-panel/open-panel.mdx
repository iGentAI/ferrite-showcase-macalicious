<Example name="basic" both />

AppKit's `NSOpenPanel`. A window without a title bar: a toolbar with Back and Forward, the
view button, New Folder, the location pop-up button and a search field; under it a sidebar
and the file browser; and a bottom bar with the application's buttons at the leading end and
Cancel and the default button at the trailing end.

The panel is assembled from the library's own parts: the [Window](/components/window) frame,
the [Toolbar](/components/toolbar) with its [buttons](/components/toolbar-button),
[segmented control](/components/toolbar-segmented-control) and
[search field](/components/toolbar-search-field), two
[Pop-up Buttons](/components/pop-up-button) (on Base UI's Select), a
[Split View](/components/split-view), a [Push Button](/components/push-button) and a
[Default Button](/components/default-button). The sidebar and the browser are yours to give:
a [Sidebar](/components/sidebar) and a [Column View](/components/column-view), list view, icon
view or gallery view.

## Usage

```tsx
import { ColumnView } from "macalicious/column-view";
import { OpenPanel } from "macalicious/open-panel";
import { Sidebar, SidebarItem, SidebarSection } from "macalicious/sidebar";
import "macalicious/styles.css";

<OpenPanel
  width={914}
  height={615}
  locations={[{ value: "documents", label: "Documents", icon: <FolderIcon /> }]}
  location={folder}
  onLocationChange={setFolder}
  canGoBack={history.length > 0}
  onBack={goBack}
  openDisabled={!selectedFile}
  onOpen={() => open(selectedFile)}
  onCancel={close}
  sidebar={
    <Sidebar aria-label="Places" value={folder} onValueChange={setFolder}>
      <SidebarSection title="Favorites">
        <SidebarItem value="documents" label="Documents" />
      </SidebarSection>
    </Sidebar>
  }
>
  <ColumnView aria-label="Files" getChildren={listFolder} path={path} onPathChange={setPath} />
</OpenPanel>
```

- **The files are yours.** A page cannot read the file system, so the panel takes everything
  as props and elements and reports what the user asks for: a place chosen from the location
  button, Back and Forward, a view, a search text, Open and Cancel. Answer by changing what the
  sidebar and the browser show.
- **The location button** lists `locations`: the path to the current folder, then favourite
  and recent places, with `separatorBefore` between the groups. It stays centred on the panel.
- **The view button** shows and reports one of `icon`, `list`, `column` and `gallery`; render
  the matching view as the children.
- **The default button** is disabled with `openDisabled` until something that can be opened is
  selected. Rename it with `prompt` ("Choose", "Import").
- **Closing** the panel is the application's: stop rendering it from `onOpen` and `onCancel`.
  While it is shown, give the window it was opened from `state="main"`.
- **Other languages.** The names of the toolbar's controls are English; replace any of them
  with `labels`.
- Glyphs for the sidebar and the files are yours to supply; Finder's are Apple artwork and are
  not part of the library.

### Options and the application's buttons

<Example name="options" both />

`leading` puts the application's own buttons at the leading end of the bottom bar, as
TextEdit's "New Document" and "Options". `accessory` is the accessory view
(`NSSavePanel.accessoryView`): the application's options, shown between the browser and the
bar. Show and hide it from your Options button.

### The browser alone

`OpenPanelBrowser` is the toolbar, the sidebar and the browser without the window and the
bottom bar, with the same props. The expanded [Save Panel](/components/save-panel) is built
from it; use it yourself to choose a file inside a [Sheet](/components/sheet).

## Guidelines

From the Human Interface Guidelines for macOS,
[Dialogs](https://web.archive.org/web/20200503145009/https://developer.apple.com/design/human-interface-guidelines/macos/windows-and-views/dialogs/)
(not verified against the archived page; paraphrased from the measured spec):

- Use the system's Open dialog rather than a design of your own, so that choosing a file
  works the same way in every application.
- Open the panel on the folder the user last chose from.
- Show only what the application can open, or dim the rest.
- The default button is enabled only while the selection can be opened.

| A pop-up button's menu open | Button drawn as a toolbar button that is on | Provisional: no screenshot |
| Not key (`state` `main` or `inactive`) | No accent on the default button; flat toolbar when inactive | Provisional: no screenshot |
| Sheet presentation | Use `OpenPanelBrowser` in a sheet | Provisional: no screenshot |

## Sizes

One size of controls. The panel is resizable in AppKit; here its size is `width` and `height`
(the captures are 914 x 615 pt and 799 x 448 pt). The toolbar is 42 pt and a 1 pt line; its
controls are 22 pt high and 11 pt from the sides; Back and Forward are 24.5 pt wide, the view
and New Folder buttons 44 pt, the location button 207 pt; the search field starts 66.5 pt
after the location button and takes the rest. The sidebar is 155 pt wide at first
(`sidebarWidth`) and is resized with the divider. The bottom bar is 41 pt under a 1 pt line;
Cancel and the default button are at least 77 pt wide
(`--mac-open-panel-button-min-width`).

## Accessibility

- The panel is a `dialog` named "Open"; pass `aria-label` or `aria-labelledby` for another
  name. It does not make the rest of the page inert or contain focus, so it does not set
  `aria-modal`: move focus into it when you show it, and back when you close it.
- Return activates the default button and Escape (and Command-Period) activates Cancel from
  anywhere in the panel, unless the focused control uses the key itself: an open menu, a
  button, a search field that holds text. Neither answers while the panel is not key.
- Command-F moves to the search field.
- The toolbar is one tab stop named "Navigation"; the arrow keys move between its controls.
  Back, Forward, New Folder, "View", "Location" and the search field are named. The two pop-up
  buttons are Base UI Selects: Space or the arrow keys open them, typing selects.
- The divider after the sidebar is a focusable `separator` named "Resize sidebar"; the arrow
  keys move it.
- Name the sidebar and the browser you give (`aria-label`). In the browser, Return on a file
  should open it: pass the view's own action callback (`onItemAction`), which then keeps the
  key from the default button.
- In forced-colours mode the bars keep their lines in system colours.

## Visual comparison

`open-panel.visual.json` compares regions of the panel with TextEdit's Open dialog in both
appearances. From the Documents captures (914 x 615 pt): the toolbar, the bottom bar, and the
start of the sidebar with the header band and the first file rows. From the iCloud Drive
captures (799 x 448 pt in Aqua, 914 x 615 pt in Dark Aqua), where nothing is selected: the
toolbar and the bottom bar with its disabled default button. Every region is compared twice:
whole, and with the glyphs, icons and text masked at a threshold of 0.05, which scores the
bars, bezels, lines and fills alone. Glyphs and icons are stand-ins for Apple's artwork, and
text is set in the fallback font off Apple platforms.

mismatch. In Dark Aqua the captured toolbar is a little darker towards the leading edge than
the measured gradient, which is most of its mean difference. The whole comparisons score 2 to
5% for the two bars and 12 to 14% for the browser region, nearly all of it text and icons.

Measured: the heights of the toolbar, the header band and the bottom bar, their fills and
lines, the sizes and positions of the toolbar's controls in both panel widths, the sidebar's
width and divider, the buttons' sizes and spacing. Provisional: the accessory area, the look
of a pop-up button while its menu is open, the panel when it is not key, the greatest width of
the search field, and the header band's text colour in Dark Aqua. Not
built: the preview column's content (the application's), the Go to Folder sheet, tags, Quick
Look on Space, multiple selection rules and file-type filtering, which belong to the browser
you give.
