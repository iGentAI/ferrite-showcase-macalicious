<Example name="basic" both />

The field in the middle of Safari's toolbar. While it is not being edited it shows only the
page's host, centred, with a padlock for a secure page, or a magnifying glass and the
placeholder when it is empty. Focusing it shows the whole text, left aligned and selected.
It is built on [Base UI's Input](https://base-ui.com/react/components/input); inside a
[Toolbar](/components/toolbar) the input and the accessory buttons are the toolbar's own, so
they join its arrow-key navigation.

## Usage

```tsx
import { SmartSearchField, SmartSearchFieldButton } from "macalicious/smart-search-field";
import "macalicious/smart-search-field.css";

<SmartSearchField
  value={text}
  onValueChange={setText}
  onSubmit={load}
  secure
  trailing={<SmartSearchFieldButton glyph="reload" aria-label="Reload this page" />}
/>
```

`value` is the text being edited: it changes with every keystroke (`onValueChange`), Return
hands it to `onSubmit`, and Escape puts back the text the field had when editing began or was
last submitted. After either key the field gives up the focus and shows the host again. What
it shows then is `displayValue` when given, otherwise the host of an address
(`https://www.example.com/page` shows as `example.com`; a user name and password in the
address are never shown) and any other text unchanged.

<Example name="browser" />

Native input props go to the input, so `name`, `disabled`, `readOnly`, `onChange` and `aria-*`
work as on an input. The exceptions: `className`, `style` and `ref` belong to the root element
(the bezel) and `inputRef` reaches the input, to focus it from a Command-L handler; the
preview attribute `data-force` lands on the root.

`leading` and `trailing` take `SmartSearchFieldButton`s: the Reader button, which stays filled
while `pressed`, Reload or Stop, the Reader's text options, and the audio button. Its glyphs
(`reader`, `reload`, `stop`, `text-size`, `audio`) are original drawings to the measured
sizes; pass children to draw something else.

## Guidelines

- Centre the field on the window and give it a fixed width while the window is wide enough:
  535 pt in a 1324 pt Safari window, 507 pt in a 1254 pt one.
- Show the padlock only for a page loaded over a secure connection.
- Offer the Reader button only when the page has a reader view, and replace Reload with Stop
  while a page loads.

## Variants and states

<Example name="states" both hideCode />

| State | How it is triggered | Look |
| --- | --- | --- |
| Page loaded | text in the field | Host, centred; padlock before it with `secure` |
| Empty | no text | Magnifier and placeholder, centred |
| Editing | focus in the input | Magnifier and text at the leading edge; focus ring 3 pt outside the fill and a hairline inside it, in the key window only |
| Reader on | `pressed` on the leading button | The 28 pt leading cell filled, its glyph in the field's fill colour |
| Accessory pressed | `:active` | Glyph in the text colour (provisional) |
| Disabled | `disabled` | Dimmed text and glyphs (provisional); pass `disabled` to the buttons too |
| Inactive window | `data-window-state="inactive"` on an ancestor | Flat bezel (an outline in Aqua), dimmed padlock and glyphs; the text keeps its colour |
| Forced colours | `forced-colors: active` | A solid field border; the on button in the highlight colour |

Nothing in the field animates, so there is nothing to reduce for `prefers-reduced-motion`.

## Sizes

One size: the field is 22 pt high, as wide as its container and at least 120 pt. Set `width`
in `style` for a fixed width.

## Accessibility

- A native text input. It is named by its placeholder unless `aria-label` or
  `aria-labelledby` is given; to name it with a visible label, pass the label's id as
  `aria-labelledby`.
- The centred host and padlock are a visual stand-in, hidden from assistive technology: the
  input's value is always the whole text. `secure` is therefore not announced; say so in the
  page's own status or in the label if it matters.
- A click or Tab into the field selects the whole text, so typing replaces it. Return submits
  and Escape restores; both give up the focus. Both keys are the field's own: Return does not
  also submit a form the field is in, and Escape does not also dismiss a dialog it is in.
  Keys pressed while an input method composes
  are left to it, and a key whose default your `onKeyDown` prevents is left to you.
- Accessory buttons are native buttons in the tab order, before and after the input. They
  show only a glyph, so each needs an `aria-label`. `pressed` sets `aria-pressed`.
- The focus rings of the field and of its buttons show only in the key window.
- There is no list of suggestions: the field is not a combobox. Command-L is the
  application's to handle.

The host and the placeholder are San Francisco only on Apple devices. The fallback font sets
them 5 to 15 pt wider, which would move the centred padlock and magnifier, so the comparison
examples take that width back with `--mac-tracking-regular`, the tracking token meant for a
fallback font; the text itself is still masked in the tight comparisons.

Provisional: the focus ring in Aqua (it follows the shared focus ring token, as in the dark
capture), editing with text in the field (only the empty field is captured: the magnifier is
kept and the text follows it), a pressed accessory, the disabled look, the Stop glyph, the
Reader button's on fill in an inactive window, and the text colour while editing. Not
implemented: the list of suggestions and completions, the page icon Safari shows while
editing, and the private-browsing appearance.
