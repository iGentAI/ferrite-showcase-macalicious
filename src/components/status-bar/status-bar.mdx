<Example name="basic" both />

A bottom bar is rare in Catalina, and the apps that have one draw it differently. `StatusBar`
covers the four that the screenshots and Finder call for, as variants of one strip with a
leading slot, centred content and a trailing slot.

## Usage

```tsx
import { StatusBar } from "macalicious/status-bar";
import "macalicious/status-bar.css";

<StatusBar>12 items, 250.3 GB available</StatusBar>
```

Place it last in a [Window](/components/window), below the body and any
[Path Bar](/components/path-bar); the window's bottom corners clip it.

## Guidelines

Not verified: this section paraphrases Apple's Human Interface Guidelines and was not checked
against Apple's text.

- Most windows have no bottom bar. Use one for status that concerns the whole window (an item
  count, free space) or for a few small controls that act on the body.
- Keep status text to one short line.
- A strip of commands belongs to the app that draws it; do not copy Automator's or Script
  Editor's buttons into an unrelated window.

## Variants and states

| Variant | Height | Look | Source |
| --- | --- | --- | --- |
| `information` (default) | 23 pt | Flat, small centred text | Finder's status bar. Provisional: no screenshot shows it; modelled on the measured path bar |
| `gradient` | 21 pt | Gradient command strip | Automator (measured) |
| `flat` | 23 pt | Flat command strip under a hairline | Script Editor (measured) |
| `breadcrumb` | 21 pt | Flat strip with a 12 pt label | System Information (measured) |

In an inactive window the gradient variant flattens like the title bar (provisional).

## Sizes

One size per variant, with no `size` prop: the bar is as wide as the window, and its height
follows the variant, 23 pt for `information` and `flat` and 21 pt for `gradient` and
`breadcrumb`.

## API

<PropsTable name="StatusBarProps" />

| Attribute | Values | Description |
| --- | --- | --- |
| `data-variant` | `information`, `gradient`, `flat`, `breadcrumb` | Reflects `variant`. |

Parts: `.mac-status-bar-leading`, `.mac-status-bar-center` and `.mac-status-bar-trailing`.

## Accessibility

- In the `information` variant the centred content is a live region (`role="status"`,
  `aria-live="polite"`), so a changed item count is announced. Change the text; do not remount
  the bar.
- The other variants add no role: their content (buttons, a breadcrumb) brings its own.
- Controls placed in the slots keep their own keyboard behaviour and need their own names.
