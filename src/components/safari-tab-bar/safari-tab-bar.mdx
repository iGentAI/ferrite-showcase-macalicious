Safari's tab bar has the anatomy of AppKit's [Window Tab Bar](/components/window-tab-bar) and
its own colours, title colours and new-tab cell. It is built on
[Base UI's Tabs](https://base-ui.com/react/components/tabs): the bar is the Tabs root with its
list inside, so it takes `value`, `defaultValue` and `onValueChange` and supplies the
tab semantics and arrow keys. It renders no panels: the window's content shows the selected
tab's page.

## Usage

```tsx
import { SafariTab, SafariTabBar } from "macalicious/safari-tab-bar";
import "macalicious/safari-tab-bar.css";

<SafariTabBar aria-label="Tabs" value={tab} onValueChange={setTab} onNewTab={addTab}>
  <SafariTab value="start">Start Page</SafariTab>
  <SafariTab value="example" onClose={() => closeTab("example")}>Example Domain</SafariTab>
</SafariTabBar>
```

Place it directly under the toolbar. The bar is as wide as its container and divides the
width equally between the tabs.

A window with one tab shows no tab bar, and Safari then puts the new-tab cell in the toolbar.

[Toolbar](/components/toolbar) and it stands in the toolbar's lower corner, against the
window's edge.

## Guidelines

- Show the bar only when there are two or more tabs, unless the user asked to always see it.
- Title a tab with the page's title, and let a long title be cut at the end.
- Keep the new-tab button at the trailing end of the bar.

## Variants and states

<Example name="states" both hideCode />

| State | How it is triggered | Look |
| --- | --- | --- |
| Selected tab | its value is the bar's value | Lighter fill and a darker title (white in Dark Aqua) |
| Other tabs | – | Darker fill, dimmer title |
| Under the pointer | `:hover` | A tab that is not selected darkens (lightens in Dark Aqua); a tab with `onClose` shows its close button at the leading edge (provisional) |
| Keyboard focus | `:focus-visible` | Focus ring inside the cell, in the key window only (provisional) |
| Disabled | `disabled` on a tab | Dimmed title (provisional) |
| Inactive window | `data-window-state="inactive"` on an ancestor | Flat fills, dimmed titles |
| New-tab button | `onNewTab` | A 24 pt cell with a + after a 1 pt divider; while pressed the + takes the selected title's colour (provisional) |
| New-tab cell on its own | `SafariNewTabButton` in a toolbar | The same cell, 25 pt square with an edge at its top and leading sides, from 12 pt under the window's top edge to the bottom of the bar |
| Forced colours | `forced-colors: active` | System colours; the dividers, the bottom border, the + and the close cross survive |

Nothing in the bar animates, so there is nothing to reduce for `prefers-reduced-motion`.

## Sizes

One size: the bar is 25 pt high (24 pt of fill and two half-point rows) and as wide as its
container. Tabs share the width equally; set a width on a tab with `style` to pin it.

## Accessibility

- A `tablist` of `tab`s; name it with `aria-label` or `aria-labelledby`. The bar renders no
  `tabpanel`: if the page area should be announced as the tab's panel, give it
  `role="tabpanel"` and `aria-labelledby` yourself, as the second example does.
- One tab stop. The arrow keys move focus between tabs without selecting, so passing over a
  tab does not load its page; Space or Return selects. `activateOnFocus` makes the arrow keys
  select as they move.
- A tab with `onClose` closes with Delete or Backspace while it has focus, and announces both
  keys (`aria-keyshortcuts`). The close button under the pointer is a pointer affordance
  only, hidden from assistive technology, because a button cannot sit inside a tab.
- When a tab is removed while it has the keyboard focus, the next tab that is not disabled
  takes the focus, or else the nearest one before it, so the arrow keys keep working in the
  bar. Focus that the application has already put elsewhere is left where it is.
- The new-tab button is a separate native button after the tab list, named "New Tab"
  (`newTabLabel`). `SafariNewTabButton` is a native button with the same name (`aria-label`
  renames it) and, in a `Toolbar`, one of the items the arrow keys move between.
- An `icon` is decoration beside the title: give an image an empty `alt`, or `aria-hidden`.
- Control-Tab, Command-T and Command-W are the application's to handle.
