<Example name="basic" both />

AppKit's `NSPathControl` in its standard style, as Finder draws it under a search. Base UI has
no breadcrumb, so it is written here on the WAI-ARIA breadcrumb pattern: a `<nav>` named "Path"
holding an ordered list.

## Usage

```tsx
import { PathBar, PathBarItem } from "macalicious/path-bar";
import "macalicious/path-bar.css";

<PathBar>
  <PathBarItem icon={<DiskIcon />} onActivate={() => open("/")}>Macintosh HD</PathBarItem>
  <PathBarItem icon={<FolderIcon />} onActivate={() => open("/Users")}>Users</PathBarItem>
  <PathBarItem icon={<FolderIcon />}>Documents</PathBarItem>
</PathBar>
```

Place it after the `WindowBody` of a [Window](/components/window), above a
[Status Bar](/components/status-bar) when both are shown. Without children it is the empty bar
Finder shows while nothing is selected. Icons are yours to supply; the library ships none.

## Guidelines

Not verified: this section paraphrases Apple's Human Interface Guidelines and was not checked
against Apple's text.

- Show the path from the root to the selected item, or to the window's folder when nothing is
  selected. The last component is the item itself.
- Use display names, as the title bar does.
- In Finder a double click opens a component. On the web a single click is what people expect
  of a breadcrumb: set `activation="click"`.

## Variants and states

| State | How it is triggered | Look |
| --- | --- | --- |
| Empty | no children | The 25 pt bar alone (measured) |
| With components | `PathBarItem` children | Icon, name and a chevron after every component but the last (provisional) |
| Component pressed, focused | `:active`, `:focus-visible` | provisional; the focus ring shows in the key window only |

A component with `onActivate` is a button; without it, plain text.

## Sizes

One size: the bar is 25 pt high (measured) and as wide as the window. Icons are 16 pt and the
chevrons 5 by 8 pt (both provisional: every captured path bar is empty).

## Accessibility

- A navigation landmark named "Path"; pass `aria-label` to rename or translate it. The
  components are list items in order.
- The last component carries `aria-current="page"`; set `current` on an item to move or remove
  the mark.
- A component that can be opened is a native `<button>` in the tab order. A pointer opens it
  with a double click by default; Return, Space and assistive technology always open it at once.
- Icons are decorative and hidden; the name labels the component.
