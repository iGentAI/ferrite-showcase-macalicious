In AppKit every toolbar item has a label, and the toolbar's display mode decides whether it
shows. `ToolbarLabelledItem` wraps one toolbar control and gives it that label: an 11 pt line
centred under the control, which is also the control's accessible name.

## Usage

```tsx
import { Toolbar } from "macalicious/toolbar";
import { ToolbarButton } from "macalicious/toolbar-button";
import { ToolbarLabelledItem } from "macalicious/toolbar-labelled-item";
import "macalicious/toolbar-labelled-item.css";

<Toolbar displayMode="icon-and-label" aria-label="Disk Utility">
  <ToolbarLabelledItem label="First Aid">
    <ToolbarButton onClick={firstAid}>{/* glyph */}</ToolbarButton>
  </ToolbarLabelledItem>
</Toolbar>
```

The child is one control: a [Toolbar Button](/components/toolbar-button), a
[Toolbar Segmented Control](/components/toolbar-segmented-control) or a pull-down button.

## Guidelines

Not verified: this section paraphrases Apple's Human Interface Guidelines and was not checked
against Apple's text.

- Labels are one or two words in title-style capitalisation, without ending punctuation; verbs
  where the item is a command ("Erase", "First Aid").
- Give every item a label even in a toolbar that shows icons only: it names the control, and
  it is there when the display mode changes.
- These are command items. The selectable icon-and-label items of a preferences window are a
  different control.

## Variants and states

<Example name="display-modes" both />

The item reads the display mode from the nearest ancestor that carries `data-display-mode`,
which a [Toolbar](/components/toolbar) sets:

| Display mode | What shows |
| --- | --- |
| `icon-and-label` | Control and label |
| `icon-only` | Control only; the label still names it |
| `label-only` | Label only; a single control covers the label invisibly and takes the click. A segmented control keeps its segments and its label, because one label cannot stand for several actions (provisional) |
| none (not in a toolbar) | Control and label |

| State | How it is triggered | Look |
| --- | --- | --- |
| Disabled | a disabled control inside, or `disabled` on the item | Dimmed label |
| Inactive window | `data-window-state="inactive"` on an ancestor | Dimmed label (provisional) |

## Sizes

No sizes: the item is as wide as the wider of its control and its label, and as high as the
control (at least 22 pt) plus, in `icon-and-label` mode, a 2 pt gap and the label.

## Accessibility

- The label is the control's name: unless the control has an `aria-label` or `aria-labelledby`
  of its own, the item gives it `aria-labelledby` pointing at the label. That holds in every
  display mode, also while the label is not displayed.
- The label is not a second focus stop and takes no click of its own, except in `label-only`
  mode, where the control lies over it.
- For a segmented control the label names the group; its glyph-only segments still need their
  own names.
